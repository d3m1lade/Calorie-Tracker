# 🔥 FitTrack — Calorie & Macro Tracker

A modern, fast, and responsive daily calorie and macronutrient tracker built with **100% vanilla HTML, CSS, and JavaScript**. Zero dependencies, zero build steps, and no backend needed — all data is persistently stored directly in your web browser via `localStorage`.

---

## ✨ Features

- **Daily Calorie Dashboard**:
  - Live consumed vs. daily target calories.
  - Dynamic status indicator (`On Track`, `Near Target`, or `Over Budget`).
  - Animated SVG circular gauge and progress bar.
- **Macronutrient Tracking**:
  - Targets and real-time intake meters for **Protein**, **Carbs**, and **Fat**.
  - Visual gram totals and percentage breakdowns.
- **Meal-by-Meal Logging**:
  - Grouped categories: **Breakfast**, **Lunch**, **Dinner**, and **Snacks**.
  - Subtotals for item count and calorie sums per meal.
  - In-place editing and deletion of entries.
- **Date Navigation**:
  - Jump across days with previous/next controls, a dedicated `Today` button, or the integrated calendar picker.
  - Full tracking history retained per date.
- **7-Day Trend Chart**:
  - Pure HTML/CSS vertical bar chart showing weekly calorie intake against your goal.
  - Click any bar to instantly view that day's log.
- **1-Click Quick Presets**:
  - Pre-loaded staples (Oatmeal, Eggs, Grilled Chicken, Brown Rice, Greek Yogurt, Salmon, Protein Shake, etc.) for instant logging.
- **Goal Customization**:
  - Customize daily calorie and macro gram targets anytime.
- **Data Backup & Restore**:
  - Export logs and goals to a `.json` backup file.
  - Import previous backups.
  - Clear individual days or reset all data.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic, accessible markup.
- **Vanilla CSS3**: Responsive design with Flexbox and CSS Grid (strictly no CSS variables or preprocessors).
- **Vanilla JavaScript**: Pure ES6+ handling data calculations, DOM updates, and `localStorage` persistence.

---

## 🚀 Getting Started

No build tools or installation needed!

1. Clone this repository:
   ```bash
   git clone https://github.com/d3m1lade/Calorie-Tracker.git
   ```
2. Open `index.html` in any modern web browser:
   - On macOS: `open index.html`
   - On Windows: `start index.html`
   - Or simply double-click `index.html`.
